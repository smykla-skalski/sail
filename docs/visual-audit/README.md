# Desktop visual audit

Run `SAIL_VISUAL_AUDIT_DIR=/tmp/sail-visual-audit mise exec -- npm run test:e2e` after `mise exec -- npm run build:e2e` to capture every frame. The visual spec uses a temporary Git repository, creates a real worktree, starts a local ACP test agent, opens a real file diff, and exercises 16 deterministic project and thread layouts. The pane spec captures two and three pane layouts and restored state. The settings spec opens the native settings window from the gear and Command-comma, checks theme persistence, and switches between windows. The tests check 1280×850, 850×650, 520×650, 390×600, and 320×500 windows. `SAIL_FUZZ_SEED=3` reruns one layout.

The tests check viewport overflow, dialog actions, composer access, settings-window access, sidebar reachability, and the agent title/status boundary. Review of the captures found and fixed the narrow window composer, mobile settings placement, worktree dialog overflow, sidebar scrolling, and long agent title overlap.

The audit cannot capture a live Architect plan or diagram without a configured model provider and plugin. The ACP conversation uses the repository's local test agent to exercise the desktop UI without external credentials.
