# Reviewed project knowledge core

This crate prepares a proposed edit from one selected private memory. It has no app command or automatic trigger. The caller must load the selected record from Sail's private memory store by ID and derive repository write access from a trusted source; neither value may come from a browser request alone.

The caller supplies the destination and proposed text explicitly. Preview reads an existing tracked root instruction file or `docs/*.md`, returns the original memory and source session, and shows the exact replacement diff without writing. It rejects destinations whose working bytes differ from the tracked Git blob, including CRLF checkouts, proposed carriage returns, and active Git `filter`, `ident`, or `working-tree-encoding` attributes. Acceptance repeats those checks before creating an artifact. Rejecting a preview only discards it. Acceptance checks write access, `HEAD`, the destination path, and the original bytes again, then prepares an uncommitted Git tree in a private temporary bare Git artifact. The artifact reads existing source objects through alternates but writes its new blob, tree, and `refs/sail/knowledge/*` ref only inside the artifact. The result returns the base revision, artifact path, and ref; `git --git-dir <artifact> diff <revision> <ref>` shows the reviewed document change. No source working file, index, ref, or object is changed, so an editor's save in the source worktree is never replaced. The caller must show the diff for review, call `discard` when rejecting it, and make a normal signed commit before sharing an approved change. Discard removes the whole artifact, including the private blob. Acceptance does not promote the tree automatically.

Issue #584 connects this boundary to the memory UI after the current settings and context changes land. Until then, this crate is exercised by its isolated behavior tests and is not exposed in Sail.
